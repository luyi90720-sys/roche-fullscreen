# 全屏助手 roche-fullscreen

让 **web 端 Roche**（浏览器里运行）自动/手动全屏。

## 功能

- **自动全屏**：打开 web 端 Roche 后，第一次点击/触摸页面任意位置即自动进入全屏（浏览器强制要求全屏必须在用户手势中调用，无法做到打开瞬间全屏）
- **手动切换**：右下角悬浮毛玻璃圆形按钮，点击全屏 / 再点退出
- 沉浸式使用，无任何文字侵入
- 状态自动同步：全屏时按钮变暗色 + 图标切换

## 安装

Roche 客户端支持"从链接安装"时，粘贴：

```
https://luyi90720-sys.github.io/roche-fullscreen/manifest.json
```

装完右下角就会出现悬浮全屏按钮。

## 浏览器支持

| 环境 | 支持情况 |
|---|---|
| 安卓 Chrome | ✅ 一键全屏 |
| PC 浏览器（Chrome/Edge/Firefox） | ✅ 一键全屏 |
| iOS Safari | ❌ 苹果限制网页全屏；请用「添加到主屏幕」后全屏运行 |

## 文件结构

| 文件 | 说明 |
|---|---|
| `manifest.json` | 插件清单（安装入口） |
| `fullscreen.js` | 插件主体：悬浮按钮 + Fullscreen API 控制 |
| `index.html` | 演示页（可直接访问体验效果） |
